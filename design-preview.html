Design notes — for review, not part of the app.
  • Zero chrome emoji. Headers are datasheet-style numbered kickers (Rajdhani, tracked small caps + hairline rule). The only iconography is a 10-icon inline SVG set for functional controls — identical rendering on every OS.
  • One accent. Steel blue marks interactive elements and key result values (OD, current) only. Green/amber/red appear exclusively as engineering judgements — fit status, corrected ratings, warnings. If a colour is on screen, it means something.
  • Pills survive only as status badges. Category labels are plain text. The amber "book value only" badge is your tolerance flag from the gland recommender upgrade.
  • Density kept. Spec grid packs 13 datasheet fields into the same space as before; mono numerals, units set small and muted, keys in small caps like a Draka table header.
  • Toggle the theme (top right) — light mode is a full equivalent, not an afterthought.
