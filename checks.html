M.E.T. — Data Sanity Checks

Runs automatic consistency checks over the cable, gland, motor, IS and ATEX data files, and confirms that linked assets exist. It catches transcription slips (a range typed backwards, a missing OD, a size list out of order) — it can't tell you a value disagrees with the datasheet. Open this page after editing any js/data-*.js file. Serve the folder over http (e.g. python3 -m http.server) so the asset checks can run.
